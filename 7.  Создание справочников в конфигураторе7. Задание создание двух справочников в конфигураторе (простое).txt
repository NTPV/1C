Разработайте описанные ниже справочники

1. Должности
Для каждого сотрудника из справочника "Сотрудники" должна быть возможность указать должность. Должность нужно выбирать из списка, который нужно хранить в информационной базе. Список должен быть с возможностью пополнения.
Создайте справочник "Должности", наполните его данными и обеспечьте возможность выбрать должность для сотрудника (элемента справочника "Сотрудники").

2. Справочник "Номенклатура поставщиков"
Один и тот же товар может закупаться у разных поставщиков. При этом наименование товара, которое хранится в информационной базе может отличаться от наименования товара, которое поставщик указывает в приходной накладной.

Например, в информационной базе в справочнике "Номенклатура" есть товар, который называется "Телевизор Samsung QE50Q67TAU", но у одного поставщика (Поставщик № 1) этот же товар называется по-другому "Телевизор Samsung (модель QE50Q67TAU)", у другого поставщика (Поставщик № 2) этот же товар называется "ЖК-телевизор Samsung QE50Q67TAU". 

Нужно создать справочник "Номенклатура поставщиков" для того чтобы четко понимать какое наименование товара используют разные поставщики. Фактически нужно хранить соответствие "Наша номенклатура Номенклатура поставщика". Эта информация в дальнейшем потребуется для ускорения ввода документов "Поступление товаров".

Для каждой номенклатуры поставщика нужно хранить следующую информацию:

Наименование (поставщика)
Артикул (поставщика)
Номенклатура (наш товар, выбирается из справочника "Номенклатура")
Поставщик (выбирается из справочника "Контрагенты")
Создайте справочник "Номенклатура поставщиков" и наполните его данными.
